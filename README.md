# SN68 MOL submissions

Public storage for encrypted small-molecule submission files for Bittensor SN68 NOVA.

Only encrypted submission payloads belong in this repository. Research code,
candidate banks, credentials, and wallet files are kept separately.

Timelock encryption delays disclosure until the designated Drand round. It does
not make submitted molecules permanently private.

This repository is initialized for setup. No live MOL submission has been made.
